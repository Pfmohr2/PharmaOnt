# Phase 7 Pilot Readiness

Focused pilot package for one bounded therapeutic area:

**Pilot scope:** aspirin antiplatelet curation for COX/PTGS targets in cardiovascular secondary prevention.

Use these documents together:

- [antiplatelet-aspirin-pilot-plan.md](antiplatelet-aspirin-pilot-plan.md) - onboarding plan, roles, setup steps, connector/source setup, and training outline.
- [dataset-checklist.md](dataset-checklist.md) - required pilot data, shapes, source versions, provenance, evidence, license, and governance checks.
- [success-criteria-kpis.md](success-criteria-kpis.md) - explicit pilot success criteria and KPI targets using a P7-OBS-KPI-compatible shape.

Non-goals for this pilot:

- Expanding beyond the aspirin/antiplatelet mini-domain.
- Treating FAERS/openFDA reports as causal evidence.
- Bypassing governed review, RBAC, release validation, or server-side authorization filters.
- Shipping a pilot with unresolved P0/P1 defects in any workflow used by the pilot.
